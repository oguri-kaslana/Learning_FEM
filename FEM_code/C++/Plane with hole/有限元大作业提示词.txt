
请为我生成一个完整的 C++ 有限元大作业项目，用于完成“带中心椭圆孔矩形板的四节点四边形等参元有限元分析”。

这是二维平面应力问题。原始问题为：矩形板中间有椭圆孔，左端固定，右端施加均布拉伸载荷 q，厚度 t = 1 mm，材料参数 E = 110000 MPa，nu = 0.3，长度 L = 84 mm。要求使用四节点四边形等参元 Q4 进行有限元建模分析，输出位移、应变、应力，并分析椭圆孔轴比 b/a 从 1 到 5 变化时孔边应力云图变化。附加题要求实现 Jacobi、高斯-赛德尔、SOR 等迭代法并比较计算效率。

本项目采用 C++ 实现有限元主体计算，MATLAB 只负责读取 C++ 输出结果并绘图。

请注意：

1. 本项目采用 1/2 板模型，不采用 1/4 板模型。
2. 原问题左端固定、右端受拉，关于竖直中线不对称，因此不能严格简化为 1/4 板。
3. 原问题关于水平中线 y = 0 对称，因此可以取上半板进行计算。
4. 代码中需要同时实现基础版本和加速版本。
5. 如果某一过程存在多种算法或多种加速方案，必须全部写出，并提供 main 函数开头的切换接口。
6. 每个主要函数文件都必须加入计时功能。
7. 所有求解器、装配方式、矩阵存储方式、后处理方式、并行方式都要输出耗时、残差、迭代次数、结果误差和加速比。

============================================================
一、总体建模要求
============================================================

采用上半板模型。

完整板坐标范围：

x ∈ [0, L]
y ∈ [-H/2, H/2]

1/2 上半板坐标范围：

x ∈ [0, L]
y ∈ [0, H/2]

椭圆孔中心：

cx = L / 2
cy = 0

完整椭圆孔方程：

((x - cx)^2) / a^2 + ((y - cy)^2) / b^2 = 1

上半板模型中只保留上半椭圆孔边界：

theta ∈ [0, pi]

上半椭圆边界：

x = cx + a cos(theta)
y = b sin(theta)

水平对称边界 y = 0 被椭圆孔切断，因此对称边界分成两段：

1. 左侧对称边界：

x ∈ [0, cx - a], y = 0

2. 右侧对称边界：

x ∈ [cx + a, L], y = 0

这两段施加对称边界条件：

v = 0
u 不约束

左端边界：

x = 0, y ∈ [0, H/2]

保持固定：

u = 0
v = 0

右端边界：

x = L, y ∈ [0, H/2]

施加均布拉伸载荷 q，方向为 +x。

因为采用 1/2 板模型，右端总外力应为：

F_total_half = q * (H/2) * t

右端每条边的一致节点力为：

Fx_node = q * le * t / 2

其中 le 为该边长度。

上边界：

y = H/2

自由边界。

椭圆孔边界：

自由边界。

1. MaterialParam
------------------------------------------------------------

功能：

管理材料参数和平面应力本构矩阵。

成员函数：

  0      0     (1 - nu) / 2 ]

============================================================
七、1/2 板网格生成要求
============================================================

请在 C++ 的 create_mesh.cpp 中实现网格生成，不依赖 MATLAB。

采用：

上半椭圆孔 + 外相似椭圆加密带 + 外部过渡区域

基本边界：

1. 内边界：上半椭圆孔

x = cx + a cos(theta)
y = b sin(theta)
theta ∈ [0, pi]

2. 加密带外边界：上半相似椭圆

x = cx + lambda * a * cos(theta)
y = lambda * b * sin(theta)
theta ∈ [0, pi]

3. 外边界：上半矩形板边界

x = 0
x = L
y = 0
y = H/2

优先采用射线法生成整个半域网格。

对 theta ∈ [0, pi] 生成从椭圆孔边界向外发出的射线。

每条射线的内点为：

P_inner(theta) = [cx + a cos(theta), b sin(theta)]

外相似椭圆点为：

P_mid(theta) = [cx + lambda * a * cos(theta), lambda * b * sin(theta)]

再从 P_mid 沿着从中心指向 P_mid 的方向延伸到上半矩形边界，得到 P_outer(theta)。

P_outer 必须是该射线与上半矩形边界 x=0、x=L、y=H/2、y=0 的交点。

特殊处理：

theta = 0:
P_outer = [L, 0]

theta = pi:
P_outer = [0, 0]

对于中间 theta，P_outer 是射线与 x=0、x=L 或 y=H/2 的最近正向交点。

径向分层：

1. 从 P_inner 到 P_mid 生成 n_inner 层加密网格。
2. 从 P_mid 到 P_outer 生成 n_outer 层过渡网格。

总径向点数：

n_radial = n_inner + n_outer + 1

周向点数：

n_theta + 1

节点矩阵：

node_grid[i_radial][i_theta]

其中：

i_radial = 0 表示孔边界。
i_radial = n_inner 表示外相似椭圆。
i_radial = n_inner + n_outer 表示外边界。
i_theta = 0 对应右侧对称边界点。
i_theta = n_theta 对应左侧对称边界点。

生成单元：

for i = 0 to n_radial - 2:
    for j = 0 to n_theta - 1:
        n1 = node_grid[i][j]
        n2 = node_grid[i+1][j]
        n3 = node_grid[i+1][j+1]
        n4 = node_grid[i][j+1]

检查单元方向，如果 detJ < 0，则交换节点顺序，使其为逆时针。

节点标记要求：

1. i_radial = 0:
   flag_hole = 1

2. i_radial = n_radial - 1 且 x 接近 0:
   flag_left = 1

3. i_radial = n_radial - 1 且 x 接近 L:
   flag_right = 1

4. i_radial = n_radial - 1 且 y 接近 H/2:
   flag_top = 1

5. theta = 0 且 x >= cx + a:
   flag_sym = 1

6. theta = pi 且 x <= cx - a:
   flag_sym = 1

对称边界包括：

右侧底边：x ∈ [cx + a, L], y = 0
左侧底边：x ∈ [0, cx - a], y = 0

孔边界本身不施加对称约束。

八、Q4 等参元理论实现要求
============================================================

四节点四边形等参元自然坐标为 xi, eta。

形函数：

N1 = 1/4 * (1 - xi) * (1 - eta)
N2 = 1/4 * (1 + xi) * (1 - eta)
N3 = 1/4 * (1 + xi) * (1 + eta)
N4 = 1/4 * (1 - xi) * (1 + eta)

雅可比矩阵：

J =
[ dx/dxi    dy/dxi
  dx/deta   dy/deta ]

detJ 必须大于 0。

通过 invJ 得到：

dN_dx
dN_dy

B 矩阵：

B =
[ dN1/dx    0       dN2/dx    0       dN3/dx    0       dN4/dx    0
  0         dN1/dy  0         dN2/dy  0         dN3/dy  0         dN4/dy
  dN1/dy    dN1/dx  dN2/dy    dN2/dx  dN3/dy    dN3/dx  dN4/dy    dN4/dx ]

单元刚度矩阵：

Ke = ∫ B^T D B t dΩ

使用 2 × 2 高斯积分：

xi = ±1 / sqrt(3)
eta = ±1 / sqrt(3)

权重均为 1。

十八、结果正确性对比要求
============================================================

当 run_mode = BOTH_MODE 时，需要同时运行基础版本和加速版本。

1. 节点数量是否一致。

7. dense 结果与 sparse 结果的位移误差。

误差计算：

error_U = ||U_base - U_fast|| / ||U_base||

error_stress = max_abs(stress_base - stress_fast) / max_abs(stress_base)

speedup = time_base / time_fast

如果误差超过 1e-6，需要在 check_info.txt 中给出 warning。

============================================================
二十一、结果分析逻辑要求
============================================================

请在 read_me.md 和必要注释中说明以下分析逻辑：

1. 当 b/a = 1 时，椭圆孔退化为圆孔，孔边应力集中相对对称。
2. 当 b/a 增大时，孔洞越来越细长。
3. 由于孔洞面积保持不变，b/a 增大时：

a = R0 / sqrt(b/a) 减小
b = R0 * sqrt(b/a) 增大

4. 孔边局部曲率变化导致应力流线更强烈弯曲。
5. 孔边最大应力通常随 b/a 增大而增大。
6. 应力云图中高应力区会逐渐向曲率较大的孔边区域集中。
7. Jacobi 方法一般最慢。
8. Gauss-Seidel 利用当前轮新值，通常比 Jacobi 快。
9. SOR 在合适 omega 下最快，但 omega 过大可能导致不收敛。
10. CG 对对称正定矩阵通常比 Jacobi、GS、SOR 更高效。
11. PCG 通过对角预条件改善收敛速度，通常比 CG 更稳定或更快。
12. dense 矩阵适合小规模问题，稀疏矩阵适合较大规模有限元问题。
13. 自由自由度缩减能减少求解规模，因此比完整置一法更快。
14. 高斯点预计算、edof 预计算、vector reserve、固定小数组、快速 I/O 都能减少重复开销。
15. OpenMP 并行适合单元刚度计算和后处理，但全局装配要避免数据竞争。
