2.1 椭圆孔面积保持不变

设基准圆孔半径为 R_0，面积为：

A_0 = \pi R_0^2

椭圆孔面积为：

A = \pi a b

面积保持不变：

\pi ab = \pi R_0^2

即：

ab = R_0^2

设：

r = \frac{b}{a}

则：

b = ra

代入得到：

a = \frac{R_0}{\sqrt{r}}, \qquad b = R_0 \sqrt{r}

说明：
- 当 r=1 时，椭圆孔退化为圆孔；
- 当 r 增大时，a 减小，b 增大；
- 孔洞面积不变，但孔形更加细长。

2.2 Inglis 椭圆孔理论解

说明：
对于无限大板中含椭圆孔的问题，在远场单向拉伸应力 \sigma_\infty 作用下，椭圆孔端部会产生应力集中。本题中远场名义应力近似取：

\sigma_\infty = q

椭圆参数方程：

x = a \cos \theta, \qquad y = b \sin \theta

椭圆曲率为：

\kappa =
\frac{ab}{\left(a^2 \sin^2\theta + b^2 \cos^2\theta\right)^{3/2}}

在椭圆上端点：

\theta = \frac{\pi}{2}

得到曲率：

\kappa_{\text{top}} = \frac{b}{a^2}

曲率半径：

\rho = \frac{1}{\kappa_{\text{top}}} = \frac{a^2}{b}

Inglis 理论中最大应力可表示为：

\sigma_{\max,\text{theory}}
=
\sigma_\infty
\left(
1 + 2\sqrt{\frac{b}{\rho}}
\right)

将：

\rho = \frac{a^2}{b}

代入：

\sqrt{\frac{b}{\rho}}
=
\sqrt{\frac{b}{a^2/b}}
=
\frac{b}{a}

因此：

\sigma_{\max,\text{theory}}
=
\sigma_\infty
\left(
1 + 2\frac{b}{a}
\right)

理论应力集中系数：

K_{t,\text{theory}}
=
\frac{\sigma_{\max,\text{theory}}}{\sigma_\infty}
=
1 + 2\frac{b}{a}

说明：
- 当 b/a=1 时，K_t=3，与圆孔无限大板经典解一致；
- 当 b/a 增大时，理论应力集中系数线性增大；
- 该理论解基于无限大板假设，本程序为有限矩形板，因此只作为精度参考。

2.3 精度评价标准

所有算法的精度统一与理论解对比。

有限元应力集中系数：

K_{t,\text{FE}} = \frac{\sigma_{\max,\text{FE}}}{q}

相对误差：

e_{K_t}
=
\frac{
\left|K_{t,\text{FE}} - K_{t,\text{theory}}\right|
}{
K_{t,\text{theory}}
}

最大应力误差：

e_{\sigma}
=
\frac{
\left|\sigma_{\max,\text{FE}} - \sigma_{\max,\text{theory}}\right|

\sigma_{\max,\text{theory}}

- 理论解主要对应孔边最大拉应力；

3.1 Q4 等参元基本公式

这一节写得简洁，只配合代码讲关键公式。

平面应力本构矩阵：

\mathbf{D}
=
\frac{E}{1-\nu^2}
\begin{bmatrix}
1 & \nu & 0 \\
\nu & 1 & 0 \\
0 & 0 & \frac{1-\nu}{2}
\end{bmatrix}

Q4 形函数：

N_1 = \frac{1}{4}(1-\xi)(1-\eta)

N_2 = \frac{1}{4}(1+\xi)(1-\eta)

N_3 = \frac{1}{4}(1+\xi)(1+\eta)

N_4 = \frac{1}{4}(1-\xi)(1+\eta)

应变与应力：

\boldsymbol{\varepsilon} = \mathbf{B}\mathbf{u}_e

\boldsymbol{\sigma} = \mathbf{D}\boldsymbol{\varepsilon}

单元刚度矩阵：

\mathbf{K}_e
=
\int_{\Omega_e}
\mathbf{B}^T \mathbf{D} \mathbf{B} \, t \, d\Omega

程序采用 2 × 2 高斯积分：

\xi,\eta = \pm \frac{1}{\sqrt{3}}

说明对应代码：
- create_Gauss()：高斯点预计算；
- create_Jacobi()：雅可比矩阵；
- create_B()：B 矩阵；
- create_K_local()：单元刚度矩阵；
- create_K_global()：总体刚度矩阵组装。

3.3 TFI 算法基本思想

给出二维 Coons Patch 形式：

\mathbf{X}(\xi,\eta)
=
(1-\xi)\mathbf{X}_{\text{left}}(\eta)
+
\xi \mathbf{X}_{\text{right}}(\eta)
+
(1-\eta)\mathbf{X}_{\text{bottom}}(\xi)
+
\eta \mathbf{X}_{\text{top}}(\xi)
-
\mathbf{X}_{\text{corner}}(\xi,\eta)

其中角点修正项：

\mathbf{X}_{\text{corner}}
=
(1-\xi)(1-\eta)\mathbf{X}_{00}
+
\xi(1-\eta)\mathbf{X}_{10}
+
(1-\xi)\eta\mathbf{X}_{01}
+
\xi\eta\mathbf{X}_{11}

解释：
- TFI 不是随机三角剖分；
- 它先定义区域边界曲线；
- 再将边界信息插值到内部；
- 适合生成规则的四边形结构网格；
- 对孔边应力集中问题，可以方便控制孔边节点密度。

3.4 本文 TFI 网格构造

本程序采用：

上半椭圆孔边界
+ 外相似椭圆加密带
+ 外部矩形边界过渡区域

内椭圆孔边界：

\mathbf{C}_{\text{inner}}(\theta)
=
\left[
c_x + a\cos\theta,\;
b\sin\theta
\right]

外相似椭圆边界：

\mathbf{C}_{\text{mid}}(\theta)
=
\left[
c_x + \lambda a\cos\theta,\;
\lambda b\sin\theta
\right]

其中：

0 \leq \theta \leq \pi

解释：
- 孔边到外相似椭圆之间为加密区；
- 外相似椭圆到矩形边界之间为过渡区；
- 孔边单元密，远离孔后逐渐变粗；
- 这样可以更准确捕捉孔边应力集中。

十、第 7 章：误差来源与可靠性分析
============================================================

写得简洁，约 300 字。

说明误差来源：
1. Inglis 理论解基于无限大板，本模型为有限矩形板；
2. 左端固定和右端加载边界会带来边界效应；
3. Q4 单元对孔边曲面和应力峰值的捕捉能力有限；
4. 孔边最大应力对网格密度敏感；
5. 单元中心应力或高斯点平均应力会影响最大应力提取；
6. 迭代法残差容限会影响线性方程组求解精度；
7. 但通过理论解对比、网格质量检查、残差曲线、求解器对比和载荷检查，可以说明结果具有可靠性。

============================================================
十一、第 8 章：结论
============================================================

结论控制在 200～300 字。

必须包含：
1. 完成了带中心椭圆孔矩形板的 Q4 有限元分析；
2. 采用 1/2 上半板模型降低计算规模；
3. TFI 网格能较好实现孔边加密；
4. b/a 增大时，孔边曲率半径减小，应力集中增强；
5. 有限元 K_t 与 Inglis 理论解趋势一致；
6. 稀疏矩阵、自由自由度缩减、预计算和快速 I/O 能提高效率；
7. Jacobi 收敛较慢，Gauss-Seidel 较好，SOR 依赖 \omega，CG/PCG 更适合较大规模有限元方程组；
8. 理论验证、网格验证和算法验证共同说明程序结果可信。
